# JOSE STORE — Grocery Website

A responsive, single-page grocery shop website made with HTML, CSS and JavaScript. No build tools required.

## Preview locally
Open `index.html` in a browser.

## Publish free with GitHub Pages
1. Create a **public** GitHub repository named `jose-store` at https://github.com/new
2. Upload `index.html` and `README.md` to the repository root.
3. In the repository, open **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**.
5. Choose branch **main** and folder **/(root)**, then press **Save**.
6. After deployment, the site will usually be available at `https://YOUR-USERNAME.github.io/jose-store/`.

## Before publishing for customers
- Product names, quantities and prices in the `products` array in `index.html` are sample data. Replace them with your real stock and prices.
- Add your shop's address, opening hours, phone/WhatsApp number and delivery details.
- The cart is a front-end demo; it does not yet submit orders or accept payments.
